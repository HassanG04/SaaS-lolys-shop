bareeq. frontend demo (plain HTML, CSS, JS - no install, no server)

Open index.html in a browser.

What works: dark/light toggle, search, category tiles and pages, best-sellers
browse with filters, cart drawer with delivery choice, demo login (customer or
admin), admin dashboard (14-day sales chart) and stock manager (edit stock, add
a product). Data is mock data in app.js and resets on refresh.

Design: follows the Shop style reference. Colours, radii and shadows are CSS
variables at the top of styles.css. Product pictures are CSS shapes standing in
for photos; swap the .art blocks for <img> tags when you have real photos.

Next step: the React + Supabase build from the project plan (Word document).
